# Paper 2: reinforcement learning for ONTS

This standalone second manuscript studies learned control of validated ONTS
search. The companion heuristic manuscript is in `../paper`.

The draft contains the problem, semi-Markov control formulation, preservation
argument, attention architecture, PPO and preference objectives, protocols,
earlier diagnostics and the profile/MILP portfolio study. It records development
results and limitations; it does not claim ONTS state-of-the-art performance.

From the repository root, regenerate numerical macros/tables and build:

```bash
.venv/bin/python -m projects.scheduling.research.render_rl_paper
bash projects/scheduling/paper2/build.sh
```

The compiled manuscript is `main.pdf`. Tables and `numbers.tex` come from saved
experiment records; the bibliography uses primary papers and proceedings.

all independently replayed as feasible and nondegrading, with no overruns.

The sixth development study implements ReSched-inspired attention, MIStar-inspired
memory and multiple proposals, coefficient-graph RL-LNS, and RL-controlled ALNS.
Its shared engine permits feasible deterioration of a working state while
preserving the best feasible output. Implementation boundaries, reproduction
commands and controls are documented in
[RL_LITERATURE_IMPLEMENTATIONS.md](../research/RL_LITERATURE_IMPLEMENTATIONS.md).
The frozen run is `../research/results/rl-literature-20261006`; its paper section
is `alternatives.tex` and its generated table is `tables/literature_summary.tex`.
This short training study evaluates ONTS adaptations; it does not reproduce
the original papers' benchmarks or establish published SOTA performance.

The new study finishes with 252 independently validated evaluations and no
